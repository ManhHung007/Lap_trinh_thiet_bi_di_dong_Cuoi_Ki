# Hướng dẫn cài đặt
## Yêu cầu môi trường
Cần cài đặt trước:
- Node.js
- npm hoặc yarn
- VS Code
- Expo Go (Android/iOS)
## Clone project
```bash
git clone <link-repository>
```
## Di chuyển vào thư mục project
```bash
cd ShopApp
```
## Cài đặt các thư viện cần thiết
```bash
npm install
```
hoặc
```bash
yarn install
```
# Hướng dẫn chạy project
## Khởi động project
```bash
npx expo start
```
hoặc
```bash
npm start
```
## Chạy ứng dụng
Sau khi project khởi động thành công:
- Nhấn `a` để chạy Android Emulator
- Nhấn `i` để chạy iOS Simulator
- Hoặc quét mã QR bằng ứng dụng Expo Go trên điện thoại
## Dừng project
Nhấn:
```bash
Ctrl + C
```
trong Terminal để dừng server.
